What each level does

LevelDefenseLesson
low None Baseline — unlimited guesses, verbose errors.
medium 1.5s delay per attempt Rate throttling slows but does not stop an attack.
high Per-request anti-automation token Tools must parse a fresh token from each response.
impossible Account lockout after 5 fails Lockout defeats naive online brute force.

Getting started

  1. Open the login target.
  2. Try a few passwords by hand to learn the form.
  3. Point an automated tool at it (see the student guide).
  4. Prove success by capturing the flag shown after login.

There are several valid accounts with weak passwords. One is admin. The rest are for you to discover.
